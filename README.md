# 📅 Meeting Notifier

Meeting Notifier is an Android application developed using Flutter that automatically detects meeting links from incoming notifications and stores them for quick access.

## 🚀 Features

* Automatically captures meeting links from notifications
* Supports Google Meet, Zoom, Microsoft Teams, Webex, and JioMeet links
* Stores meetings locally using SQLite
* View all detected meetings in one place
* One-click meeting joining
* Notification reminders for detected meetings
* Simple and user-friendly interface

## 🛠️ Technologies Used

* Flutter
* Dart
* Kotlin
* Android Notification Listener Service
* SQLite Database
* Method Channels

## 📱 How It Works

1. User grants Notification Access permission.
2. The app listens to incoming notifications.
3. Meeting links are detected automatically.
4. Meeting details are stored locally.
5. Users can view and join meetings directly from the application.
